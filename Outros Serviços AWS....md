A AWS oferece serviços personalizados para necessidades específicas, como simplificar a implantação de aplicativos web, gerenciar workloads em lote, fornecer servidores virtuais e estender a infraestrutura em nuvem para data centers locais.

> **Elastic Beanstalk**

Serviço **PaaS** totalmente gerenciado: o desenvolvedor faz o upload do código, e o Elastic Beanstalk provisiona sozinho a infraestrutura (EC2, Auto Scaling, Load Balancer, monitoramento). Compatível com Java, .NET, Python, Node.js, Docker etc. O usuário **ainda tem acesso e controle** dos recursos criados por baixo. **O serviço em si é gratuito**, paga só pelos recursos que ele cria.

|   |
|---|
|**Palavra-chave na prova**: "desenvolvedor quer só subir o código sem se preocupar com infraestrutura"|


> **AWS Batch**

Serviço totalmente gerenciado para executar **trabalhos em lote** na AWS. Programa, gerencia e dimensiona de forma automática os recursos de computação de acordo com os requisitos do trabalho.

|   |
|---|
|**Ideal para**: centenas de milhares de jobs em lote em paralelo: computação científica, análise de risco financeiro, transcodificação de mídia, pesquisa genômica|


> **Lightsail**

Oferece servidores virtuais privados (VPSs), armazenamento, bancos de dados e redes a um **preço mensal fixo e previsível**. Para quem quer simplicidade, sem a complexidade do Console da AWS completo.

|   |
|---|
|**Ideal para**: sites simples, blogs, pequenas empresas, ambientes de teste, iniciantes na nuvem|


> **Outposts**

Solução de **nuvem híbrida**: a AWS instala racks com a infraestrutura e serviços da AWS **dentro do data center do cliente**, totalmente gerenciados pela AWS.

|   |
|---|
|**Ideal para**: baixíssima latência para sistemas locais, processamento de dados local, requisitos de **residência de dados** (dados não podem sair do local)|
